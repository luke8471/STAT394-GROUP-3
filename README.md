## Project objective
Group 4: Underwater Artefacts from Gela’s Archaeological Site

and justification:
• A high-level description of the study and its motivation.
• A quantitative descriptive analysis of the data.
• A graphical/qualitative analysis of the data.
• Can you assume that the data follow a multivariate normal distribution?
• Are there “surprising” observations?
You must try to answer the question (with a proper discussion):
• Is the cluster analysis consistent with different distances and linkages?
